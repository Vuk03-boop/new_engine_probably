## Supersession guardrails

- The old engine's four-body/no-water-mottle contracts protect **that engine**. They do not dictate the new implementation.
- Older “no frame cost measured” or “do not re-measure” prose can conflict with later dated results. Read experiment configuration and chronology, not just a heading.
- Old source-existence/EOL assertions, shader-limit diagnoses and default-off cost assumptions were corrected. The ROI guide explicitly carries those corrections.
- Reports include historical measurements, interpretations and unresolved hypotheses. A historical measurement is not a fresh replicated result; an explanation is not automatically established causality.
- `CLAUDE.md`, current user scope and `docs/NOW.md` control present work. This reference directory is read-only evidence.
